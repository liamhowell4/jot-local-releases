# Jot Local downloads

Jot Local is a local dictation app for Apple Silicon Macs running macOS 14 or later.

Download signed releases from [Releases](https://github.com/liamhowell4/jot-local-releases/releases).
Install Jot Local in Applications. Updater-enabled versions check for new releases and ask before restarting.

This repository contains distribution assets and the Sparkle update feed. It does not contain the application's source code.
